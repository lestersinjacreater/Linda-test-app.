# fraudintel/: mock Safaricom fraud intelligence (demo infrastructure, NOT part of the product)

Stands in for the fraud team's systems: numbers reported to 333, blocked numbers, known scam campaigns
and the genuine official numbers. The Linda gateway talks to it only through root contract 5.12, so in
production the gateway points at Safaricom's real systems and nothing else changes.

## Rules
- Nothing in `android/`, `backend/` or `ml/` may import from here (root principle 2).
- Placeholder numbers only (254700000xxx). Never real people's numbers.
- Never accept or store message text: the report model uses `extra="forbid"`.
- The verified list is read from `shared/verified_callers.json` (one source of truth).
- `data/seed.json` is generated by `scripts/make_seed.py` (uses ml/ as a dev tool only); the service never imports ml/.

## Structure
```
fraudintel/src/
  main.py                 create_app (settings, clock injectable for tests)
  core/config.py          settings from env
  features/intel/store.py in-memory knowledge, reset from the seed
  features/intel/router.py  5.12 endpoints + demo extras (/admin/numbers, /admin/reset, inbox)
```
